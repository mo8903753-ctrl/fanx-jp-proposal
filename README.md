# FanX Drive X3 · 日本众筹整体方案

单文件提案站点：`index.html`（自包含，图片全部 base64 内嵌）。

## 构建

```
python3 build.py   # 拼接 src/*.html，把 {{IMG:name}} 替换为 img-src/ 里的 data URI
```

- `src/` — 章节零件（按文件名排序拼接）
- `img-src/` — 待嵌入图片（产品图、公司/案例图、受众照片）
- `NOTES.md` — 定案口径与事实核查记录（内部用）
